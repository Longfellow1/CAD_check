# TABBY EVO source drop zone

Place only the archive and extracted STEP file obtained through the official [Open Motors download page](https://www.openmotors.co/download/) here. Keep the original filename and record the local SHA-256, byte size, download date, configuration, and license evidence in `fixtures/manifest.yaml`.

The historical Google Drive IDs are recorded in the manifest for provenance, but currently return HTTP 404. Do not put an unverified mirror in this directory.
