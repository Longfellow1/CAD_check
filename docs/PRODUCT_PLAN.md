# Product Plan — Automotive Engineering Verification

## Product thesis
Turn repetitive automotive engineering review work into versioned, executable Verification Cases with deterministic geometry, evidence, trace and later Agent orchestration.

## Short term — Capability validation
- Prove a small number of executors cover many real rule patterns.
- Prove version regression, evidence and trace are useful to engineers.
- Earn access to real CAD data for an enterprise pilot.

## Mid term — Enterprise pilot
- CATIA/NX/Creo adapter → STEP AP242 + engineering inventory.
- Real semantic binding and binding-reuse measurement.
- OCP/OCCT BRep truth vs CATIA ground truth.
- Headroom / visibility / envelope and more check archetypes.
- Human review focused on ambiguity and exceptions.

## Long term — Verification platform + Engineering Agent tool layer
- Versioned Verification Case library.
- Cross-model / cross-program reuse.
- Rule versioning and audit.
- Regression at vehicle-node scale.
- AI for rule digitization, semantic candidate ranking, regression explanation and orchestration — never for millimeter geometry truth.
